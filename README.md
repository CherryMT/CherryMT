## 📂 Featured Projects

### 🗺️ InteliPath — Personalized Career Orientation & Learning Roadmap Platform for Software Engineering Students

**InteliPath** is an intelligent career guidance platform that helps students build **personalized learning and career roadmaps** powered by AI. The system connects three roles — **Mentor**, **Counselor**, and **Student** — creating a comprehensive ecosystem that supports career orientation and tracks real learning progress.

#### 🧑‍💻 My Role — Front-End Developer

I was responsible for building the entire **user interface** from scratch, including UI design, component development, and API integration.

**What I did:**

- 🎨 **Onboarding & Landing Page** — Spearheaded the development of the user onboarding flow and landing page, implementing complex and engaging UI animations using GSAP and Framer Motion
- 👥 **Counselor Dashboard** — Designed and built the Counselor Dashboard, providing a comprehensive interface for counselors to manage student profiles, monitor progress, and submit feedback
- 🔐 **Authentication** — Implemented full auth flow: Login, Register, Forgot/Reset Password, **Google OAuth2**, JWT + role-based route guards (React Router v7)
- ⚙️ **State & API** — Set up **Redux Toolkit** for global state management, integrated **Axios** interceptors for auth token handling & error management
- 📱 **Responsive Design** — Designed the entire application to be fully responsive using **TailwindCSS v4**

### 🌌 Developer Portfolio Website

A modern, animated, and responsive **personal developer portfolio** built from scratch. The site features a premium **"Dark Space Neon"** aesthetic with glassmorphism cards, animated gradient borders, neon glows, parallax scrolling, and fluid scroll-triggered animations. 

#### 🧑‍💻 My Role — Front-End Developer (Solo Project)

I was responsible for **designing and building the entire website from scratch**, including UI/UX design, component development, animations, and deployment.

**What I did:**

- 🎨 **Hero Section** — Built a full-screen landing area with a 3D computer model (Three.js + React Three Fiber), an animated aurora background, and a dynamic typewriter text effect
- 🗂️ **Projects Showcase & Detail Pages** — Developed a card grid for project previews and dynamic detail pages featuring browser-frame screenshot showcases, FE/BE tech stack tab switchers, and animated stat cards with cycling gradient border rings
- ✨ **Fluid Animations** — Implemented bidirectional scroll-triggered entrance animations and parallax background effects using Framer Motion
- 🤖 **AI Collaboration** — Designed and built the portfolio in close collaboration with Google Antigravity AI (Gemini) as an AI pair programmer, handling architecture, animation logic, and iterative UI refinements
- 📱 **Responsive & Performant UI** — Ensured a fully responsive mobile-first layout with smooth micro-interactions (hover shimmer sweeps, sparkle pulses) using Tailwind CSS v4
